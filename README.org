#+title: Cogent-House

This is the MQTT server part. Also see cogent-house-web

* Install instructions

** Clone submodules

={sh} git submodule update --init --recursive=

** Create and activate a virtual environment (using python3.11 if available)

#+BEGIN_SRC sh
uv venv --python 3.11 .venv
#+END_SRC

** Install dependencies
#+BEGIN_SRC sh
uv pip install -e ./tinyos3
uv pip install -e .
#+END_SRC


** Run tests
={sh} uv run pytest -q=
